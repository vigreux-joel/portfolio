Comment l'énergie se comporte-t-elle dans les connecteurs ?

Le composant Line a un flux d'énergie animé. Pour les connecteurs split/merge, quel comportement veux-tu ?

A — Flux en cascade

L'énergie descend sur le tronc, puis se divise : deux streams partent simultanément dans les deux branches.

B — Branches indépendantes

Chaque branche a son propre flux décalé dans le temps (déphasage). Le split/merge est juste un connecteur structurel.

C — Connecteur statique

Le split/merge n'a pas d'animation d'énergie — juste la révélation au scroll. Simple à implémenter.
