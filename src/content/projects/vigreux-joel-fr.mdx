## Pourquoi ce site est un projet

Un portfolio est le seul projet dont le visiteur peut juger la qualité pendant qu’il le lit. C’est aussi le seul sur lequel je décide de tout : le contenu, l’architecture, les compromis.

Je l’ai donc traité comme un produit, pas comme une plaquette.

## Les choix techniques

- **Astro** pour un rendu statique : des pages rapides, sans JavaScript inutile côté client, et une bonne base pour le référencement.
- **Udixio UI**, ma bibliothèque de composants, pour l’interface. Le site est ainsi le premier utilisateur réel du design system.
- **Des îlots interactifs ciblés** : seules les parties qui en ont besoin sont hydratées côté navigateur.

## Ce à quoi j’ai fait attention

- la navigation complète au clavier et les contrastes de couleur ;
- le poids des pages et le chargement des images ;
- des contenus structurés et des données Schema.org pour le référencement ;
- des textes écrits pour être compris, y compris par des lecteurs non techniques.

## Le code est public

Le dépôt est consultable sur GitHub. C’est la façon la plus directe de vérifier ce que valent les affirmations de ce site.
