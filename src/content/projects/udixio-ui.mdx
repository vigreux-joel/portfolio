## Le point de départ

Une interface évolue rarement d’un seul bloc. De nouvelles pages arrivent, plusieurs personnes interviennent et des différences apparaissent peu à peu dans les couleurs, les espacements ou le comportement des composants.

L’objectif d’Udixio UI est de fournir une base commune sans enfermer le produit dans une identité visuelle figée.

## Ce que le système prend en charge

- des composants prêts à être réutilisés dans plusieurs écrans ;
- des thèmes générés à partir d’une couleur principale ;
- des comportements et états cohérents au clavier, à la souris et au toucher ;
- une API TypeScript commune pour limiter les décisions répétitives.

## Mon rôle

J’ai défini les règles du système, conçu l’architecture des composants, développé la bibliothèque React et rédigé sa documentation.

Le portfolio que vous consultez utilise directement Udixio UI. Le projet est donc confronté à un usage réel plutôt qu’à une simple démonstration isolée.
